## Failures and corrections

The first Apache fixture allowed generic Options overrides. That setting prohibited the packaged `-MultiViews` directive and the game root returned 500. Explicitly granting `Options=Indexes,MultiViews` inside the game directory allowed the shipped configuration to execute. Apache without the directory-listing module returned 404 for the assets directory, while the normal listing-capable fixture returned 403. The first browser attempt selected a scene object before opening Scene. The first synthetic ledger setup omitted its required empty private lock. The successful run used the ordinary Scene window and provisioned both ledger files. One comparison of newly created sibling fixtures failed before it recorded the differing metadata field. For a stable baseline, the final fixture assigned those same site-owned files modification times two minutes before its initial GET and compared all response fields across the complete run.

An earlier CSP-bearing archive, SHA-256 `e6251c4ccaa7e203855e6d05301cec4c6dd874352952f428288fe88253236c19`, passed 78 HTTP checks plus the browser smoke. A subsequent worker-outage test exposed a 503 without Cache-Control while PHP was unavailable. Applying the cache rule at the single public PHP front controller fixed that failure in a disposable 87-request control run. The final production-shaped run exercised the rebuilt archive with all four backend-down endpoints. [Package recipe](../../../release/game.htaccess)
