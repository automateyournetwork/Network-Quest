## Optional activity scope

Each activity starts in its own prepared session without completing another
optional activity or recruiting an ally. Start, practice, finish, retry, exit,
skip, completion replay and untimed delay are separate cases. Exit covers
instructions, practice, solving and unfinished feedback. Completed activities
also retain safe exit and replay their explanation without a duplicate benefit.
An optional benefit means a cosmetic/discovery/completion record, not necessarily
an inventory item. No mandatory reward is invented for a minigame.

configuration. Restoring preparation advances freshness beyond revision 8 and
the old attempt; measurements remain visible as stale and cannot validate it.
Clues, notes and hints remain, required tools are recoverable, and no unearned
benefit appears. Detailed encounter/E03/Restore Save rollback stays with T083.

Timing starts off. **A timed mode is optional to implement.** The six timing
scenarios are conditional on the activity actually authoring that capability;
an entirely untimed implementation is valid. If offered, timing requires prior
untimed completion and explicit opt-in and must retain safe exit without a
main-score requirement. This qualification incorporates coordinator review and
prevents the oracle from adding an unrequested timer feature.

Completing an optional activity alone cannot award a main objective when its
required independent evidence is absent. The fixtures do not forbid reusing a
valid observation in the main lesson. Likewise, no direct implicit save is added
by swap/retry/exit; a separately eligible manual or opted-in safe-boundary save
continues to use the sole existing slot. Required progress/tool preservation is
