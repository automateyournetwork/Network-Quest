## Rollback and recovery decision

1. Keep the prior game code and a scoped copy of any changed game detail/listing files for restoration. Record their digests and the private rollback location in the operator record. Before a code switch, block external game ingress and quiesce web workers, jobs and other writers. Earlier releases may predate the application write drain.
2. Run the release's private `backup.php` with `drain`, then `game`. With the drain held, run `restore.php` in `rollback` mode into a new isolated candidate using the just-captured archive. The comparison checks surviving accounts, identities, preferences, exact saved bytes/revisions and retained acknowledgements with the authoritative external deletion ledger applied. A stale archive or divergent comparison keeps ingress closed.
3. Switch compatible code onto the current game database, or use a tested forward repair or coordinated migration while drained. Keep the external deletion ledger and its lock authoritative across the switch. Verify private paths, migration checksums, retained acknowledgements, isolated accounts, ordinary authenticated Continue and the affected website routes. Release the application drain with `backup.php … resume` under controlled ingress and restore public game traffic only after private verification. Limit file restoration to the game's integration boundary. [Exact CLI operations and provisioning](../../operations.md#restore-and-planned-rollback) · [Rollback evidence](recovery-drill.md)
4. For an actual loss of the primary, use the separate disaster procedure. Establish the freshest eligible encrypted backup and prove deletion-marker continuity through the incident. Restore to isolation, reconcile pending/completed deletions, invalidate restored sessions, verify surviving saves and require a new sign-in. Report the last recovered revision and age. In the T166 local disaster fixture, restoring revision 1 lost the later post-capture write as expected, with a two-second recovery point and 289.30 ms from simulated loss to authenticated read.
