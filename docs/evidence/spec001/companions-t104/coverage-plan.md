This stage runs the accepted commit `9a93bf7815cda8b7055a8177bd61d5c468dc8f52`
from an isolated archive, built normally and served with Vite production preview.
It does not use the evolving main-tree runtime. No adventure, measurement,
objective, party, reward or evaluator result is injected. Browser DOM inspection
reads rendered content only; the retained-control negative case clicks a detached
button and verifies that it cannot change the party.

One actual guest journey covers the introduction, copper, optical, radio,
equipment, Clockworks, Rift and validation balcony. It discovers the roster via
actual Look/Talk, earns nine invitations and distinct post-recruit lessons, and
compares both earned ability levels with ordinary physical controls/readings.
The fixed roster and expected supplied numeric outcomes are independent of the
rendered results. Authored content supplies control labels and source identities.

Checks cover the max-two active limit, free preparation replacement, stale
controls, historical learning versus current repair proof, cross-room source
navigation, notes versus observations, keyboard focus, 390/768/1280 px at 200%
text, and the contained adventure frame. Planned portraits remain unavailable;
these checks do not accept portrait quantities, visual media, Safari, human
learning, actual identity providers, hosting, release performance or T104 itself.

The same T104 worker must later run all SQ01–04/MG01–03 lifecycle rows on their
integrated runtime: instructions/start, untimed practice, wrong explanation,
correct finish, retry, exit before completion, replay/exit after completion and
skip/route independence. Earned nonempty optional progress plus earned nonempty
party must participate in actual encounter Retry, E03 Continue and one-slot
Restore Save. Final T104/current release regression is required after all joins;
this historical baseline cannot substitute for it.
