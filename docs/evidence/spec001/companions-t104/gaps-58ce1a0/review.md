branches; the conventional branch explicitly has no recruits or active allies.

submissions run in both branches. Each pair compares nonempty observations,

and Retry run through production APIs. The Retry measurement is generated at

`background.spec.ts` supplies that separate browser check. All game progress is
earned from the real introduction, ordinary room controls, copper/radio/market
measurements and actual SQ04 R03/R05/R09 clue acquisition. There are no recruits.
Only the existing isolated PHP test identity is synthetic; there is no provider
login. At each filled full-answer form, an owned second-tab probe did **not**
naturally hide headless Firefox. The harness therefore explicitly overrides the
document's visibility properties and dispatches `visibilitychange`, advances
Playwright's clock by one hour, and restores visibility. It asserts the actual
graybox renderer's `data-paused` switches true then false, so the application
consumer responds. The form text/values, session and room stay unchanged, with
no save during the wait. All four activities then complete and save one quest
and fact. Four manual revisions use one slot with autosave off. The final saved
state retains the earned main objectives, notes and one inspection kit. All 247
executed source/helper hashes remain unchanged; no browser errors or external
requests occurred. This is simulated time/visibility functional evidence, not a
real hidden-tab hour, a foreground benchmark, or a manual browser review.
