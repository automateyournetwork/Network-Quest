## Reproduction

The construction and verification scripts are in assets-src/characters/batch-a. To reproduce on a disposable checkout, call build.py through native Blender with the seven IDs after a double dash. Open each resulting blend in a separate Blender invocation with reopen.py, then run browser.mjs using the pinned Node runtime. Run import.py in Blender for the independent GLB reimport. contact.py uses the existing local Pillow installation. Run staging.py and clearance.mjs for the frozen layout study, then evidence.py to assemble the typed records and batch fragment. Browsing requires the project Playwright Firefox, OpenSSL and certutil. The script creates and deletes its own local trust profile.

The repository inventory command accepts the fragment through its manifest option. The final fragment-audit.json records its independent zero-issue, zero-count result.
