The action bus admits only the four closed radio intents. Select is a scalar
choice mapped to one of the four existing A/B/emitter action IDs. Predict carries
an actual baseline UUID and a threshold prediction. Compare carries an actual
later UUID plus closed comparison/threshold/prediction/inference choices. Measure
carries **only the matching session ID**; its reading UUID is generated internally.

context. Invalid keys, IDs and array-coerced enums fail at capture.

A prediction is copied into transient session state with its actual earlier
record, original notebook IDs, adventure, attempt, configuration revision and
scenario signature. The earlier revision proves ordering, not physical causation.

current proof. Configuration selection clears the prediction; attempt changes,
mode changes, restored state and changed ownership invalidate relevant captures.

The optional preparation module returns a trusted closed radio directive. The
reducer composes `prepareRadioAction` for selection or `prepareObjectiveChange`
for O08 measurement within the same optional transaction and final compare-and-set.

The runtime remains `active-optional` throughout. It is never temporarily changed
to bypass admission; raw generic radio/measurement commands remain rejected.
A failed CAS installs neither flags, readouts, assistance nor partial rewards.

was absent when predicting, which follows in notebook order, has the captured
attempt/revision, is latest/current and matches the actual resolver. It rejects
explicit staleness, old revisions with a false stale flag, wrong attempts,
retrospective prediction, altered SNR/units and changed scenario facts. Returning
to identical settings does not revive a prediction. Readout provenance is retained;
no source-case identifier or invented observation is installed on an earned record.
