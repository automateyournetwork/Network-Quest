## Implementation and boundaries

`src/state/dialogue.ts` prepares authored entry, selected choice and next-node
batches through the actual reducer. Choice effects precede next-node conditions.
Skip traverses the single eligible authored continuation, retaining later entry
clues. Ambiguous branches require a visible explicit choice, and cycles fail
closed. The caller installs only the successful final candidate once; no partial
choice, clue, item or objective batch is installed after a later failure.

The exported introduction bindings preserve the exact four canonical effects:
Photon clue uses its own dialogue-effect receipt; `EFFECT-kit` and
`EFFECT-kit-issued` share `FLAG-kit-issued` from Photon; Titan clue uses its own
dialogue-effect receipt. The satchel uses that same kit group. No generic dialogue
ID is a receipt; no new save field, objective shortcut, fabricated measurement,
player hypothesis or achievement was added. Replays use the actual once policies.

`src/ui/dialogue.ts` supplies explicit narrator Talk-source → target-dialogue
bindings to T025's `InteractionPlanner`, a transient session controller and a
passive native DOM panel. It requires once policies for entry/choice effects.
Entry/choice conditions and room/hotspot/action membership are checked against
actual registered content. Node/session UUID checks reject old line, closed or
reopened controls; each authoritative projection retains its original bus
capture scope across late presentation redraws. External GameState replacement
invalidates the session even when version numbers match.

An open conversation holds the existing reducer's empty `dialogue-transaction`
transition. Each choice/replay/skip prepares its lock commit, authored batches and
next empty lock locally, then installs once. Finish and Close restore the exact
prior safe activity. Ordinary verbs, inventory selection and notebook opening
are unavailable behind the conversation, and a safe-state save cannot classify
it as stable exploration. A failed branch leaves the original lock and world
unchanged. Invalidate/dispose cancel only a still-current matching lock, retain
already recorded clues, and never install an abandoned world. No reducer change
or fabricated state patch was needed.

Completed topics remain replayable after successful room-local canonical reducer
actions whose command receipt and prior context match. Arbitrary replacement
cannot revive the prior topic. Finish/Skip hide the `Dialogue` dialog and leave a
visible `Replay dialogue` button, matching the prepared guest vocabulary.

Native buttons support pointer/touch/Enter/Space; Escape closes the conversation.
Every line is literal readable text, independent of audio, animation or imagery.
The panel preserves focused controls on redraw, moves focus to the next line's
heading when its old choice disappears, and restores the opener after close or
finish. Replay remains visible outside the closed dialog. No required content
is communicated only through sound or color.
