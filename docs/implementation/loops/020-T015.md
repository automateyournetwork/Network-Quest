## Concrete improvement and interfaces

- `src/content/registry.ts`: pure `validateContent({ world, sources, documents })`
  returns bounded diagnostics or immutable membership/record/safe-position
  lookups and counts. Inputs are decoded JSON; runtime code imports no filesystem,
  private configuration, network, schema compiler or provider service. A tooling
  preflight with `allowUnloadedDocuments` returns paths and **no usable registry**.
- Structural checks use `content/schemas/content.schema.json` compiled with strict
  Ajv2020/formats. `schema.generated.js`, its declaration and
  `schema-types.generated.ts` are mechanical projections generated by the CLI;
  exact synchronization is tested. Standalone static helpers work under Node and
  Vite without dynamic code generation. Generated validator is approximately
  700 KB source, not the app's currently shipped payload.
- `tools/validate-content.ts`: Node-only schema generation/drift checking and
  UTF-8 JSON loading. Paths are constrained to `content/spec001`, resolved paths
  cannot escape via symlinks, and files are bounded to 4 MiB. No package script,
  dependency, lock or harness configuration changed. `--generate` updates the
  mechanical artifacts; ordinary invocation rejects drift.
- Semantic checks cover kind-specific membership, identity collisions and suffix
  agreement, duplicate/contradictory definitions, source mappings/cases/claims,
  exact reviewed profile parameters/assumptions/limits, physical reading
  dimensions, metadata allocations, all fourteen edges, independent branches,
  common O09/O10, optional/future separation, source coverage, conventional
  equivalents, effect ownership, item acquisition/consumption/recovery, dialogue
  nodes/exit cycles, and explicit safe-anchor geometry in simple walk polygons.
- Every metadata objective and forward walk prerequisite is checked over all
  4,096 objective-completion combinations. This rejects missing common gates,
  altered branches, cyclic dependencies and early walk access, while accepting
  logically equivalent expressions and reordered records.
- Source `Mb/s` and `toy-level` remain unchanged in source parameters. Runtime
  readings retain the save-v1 unit vocabulary. `reviewedRateToMbps` explicitly
  converts the reviewed decimal rate spelling without scaling; no toy symbol is
  silently interpreted as volts.
- Schema has no separate action/flag/media declaration catalog. Authored
  alternatives/choices/combinations declare actions; `set-flag` effects declare
  flags; evidence/character records declare facts/abilities. Unknown uses fail.
  Media asset IDs have structural validation here; actual manifest membership,
  editable-source/export/license/use and human media acceptance remain their
  later tasks. World metadata is never a playable authored record.

Strict compilation with `inlineRefs: true` passes. An exploratory
`inlineRefs: false` compile exposed a `strictRequired` diagnostic for nested
`parameter.not` unit/value declarations. Kept the established strict inline
setting; did not disable strict checks or change the authoritative schema. This
is an alternative compiler-option observation, not a failed schema acceptance.

## Coordinator review correction and handoff

Coordinator review identified two flaws in the initial authored capability
closure: retaining historical flag values and following only the first ordinary
alternative/catalog ordering. Replaced that closure before acceptance with
bounded concrete-state exploration. Each state owns its current flag values,
quantities, acquisition history, applied effects, active dialogue node and
transformation recovery policy. Each eligible objective ordering and conventional
alternative creates an independent successor. Atomic consumption is affordable
before grants; alternative histories cannot be merged. Pickup occurs only once;
consumed items return only through currently available explicit recovery. Dialogue
choices and item combinations retain exactly-once effect/combination identities.
Deterministic visited keys deduplicate states.

New regressions prove a dead-end first/viable second alternative is accepted,
mutually exclusive flag histories and overwritten values cannot jointly satisfy
a later prerequisite, common preparation can occur in a valid order different
from the catalog, and a consumed prerequisite is reacquired only when its actual
recovery is available. An accessible dialogue can supply a main-story flag;
authored optional cycles are checked separately from the main-story routes.

Analysis has a **4,096 distinct concrete-state ceiling per branch**. Exceeding it
returns explicit `graph-bounds` / reachability-unproved diagnostics and no usable
registry, even if a completion was encountered earlier. A regression deliberately
exceeds the ceiling. Complex future authored content may require separately
analyzed search optimization or a reviewed bound change; there is no unbounded
search or silent pass. Conditions also have depth/node and 256-alternative DNF
bounds. This shared authoring proof does not implement the future domain evaluator,
reducer or presentation, and does not certify human learning or playability.
