## Stable integration API

- `createNavigation({registry, world, entries})` accepts the validated registry,
  matching `world.rooms`/`world.walkEdges`, and explicit `NavigationEntry[]` with
  `roomId`, `safePositionId`, `activity`. It detaches metadata/bindings and returns
  pure `resolve(world, targetId, safeActivity)` and `canReachRoom(world, roomId)`.
  `resolve` returns an identified safe destination or an explanatory failure.
- `canReachRoom` is the reducer's existing trusted recovery port. It checks both
  directed paths under the supplied candidate world, requires actual authored
  exits/eligible entry geometry at every step, and refuses metadata-only future
  content. Deterministic sorted breadth-first traversal is bounded to 128 rooms
  and 1,024 metadata edges. The zero-step case still requires a real safe current
  position. Recovery cannot authorize consumption if the candidate effects close
  the path or a route exists in only one direction.
- `createNavigationPlanner({navigation, store})` supplies T025's `walk` option.
  Only matching current-room `interact`/Walk/null-item intent is accepted. It
  refuses unsafe activities/pending transactions, uses the existing reducer
  plan/store compare-and-set, and never cancels another controller's lock.
- `createSceneObjectProjection({registry, navigation})` supplies T025's optional
  `sceneObjects(state, hotspots)` port. `createVerbController.objects()` first
  computes its existing hotspot alternatives, then the port appends the actual
  exits, walk regions and safe positions. It checks exact hotspot membership,
  keeps authored labels/descriptions/actions, exposes readable unavailable
  reasons and produces the same semantic intents for native and visual clients.
  Without the port, T025's previous projection remains unchanged.
- T029 must explicitly bind R01/R01.entry and R02/R02.entry, normally with
  `stable-exploration`, install `navigation.canReachRoom` in `createReducer`, and
  provide the two UI ports. Pass matching validated metadata/registry, never a
  renderer-owned graph. Restore/title/logout must still invalidate the existing
  action bus epoch. No main wiring is part of T028.
