## One-slot behavior

The frozen read catalog includes memberships, quantities, recruit and hint relationships, objective dependencies, measurement rules and safe anchors. Its version and permissions are independent of subsequent content edits. The current-only validator continues to govern all newly submitted bodies. PHP permits a conditional current-version save over an existing schema-1/0.9.1 row. Its receipt checks, transaction, precondition handling and one-row constraint still govern the write. The GET transport now carries the stored JSON member's leading and trailing whitespace as well as its interior bytes. The earlier server response already embedded those bytes.
