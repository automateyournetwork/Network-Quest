## Room fit

Firefox rendered the ten room-specific props and all allocated shared tools from each R02–R12 camera at 1280 × 720. Each room has a frozen placement pass and a second pass with proposed fit corrections. Both have a color capture, an opaque identity pass, projected rectangles, individual pixel counts, exact fixture input hashes and transforms. No resident, party member or final scenery was added to these studies. Run browser.mjs with the pinned Node runtime and all thirty PR-prefixed IDs. The mounting inputs use the matching saved parent models.
