  auth start/callback, logout, save, preferences and account/deletion-status paths.
  Unimplemented operations return honest503; unknown paths404; unsupported methods
  405 with Allow. Malformed/ambiguous paths400, no percent decoding or filesystem
  fallback. Game/API prefixes may change together through validated public routing
  options. HEAD errors have no body.
- JSON errors follow the existing `{code,message,requestId}` Problem contract with
  generated UUIDv4 identifiers. Callback503 is accessible inert HTML and contains

  content-type/indexing headers. No success session/save/deletion, cookie, provider
  navigation, private config load, request-body read, DB or session startup exists
  in the real router. No raw request/exception logging was introduced.
- `server/public/index.php`: sole service entry and CLI-server router; never returns
  false to let PHP serve arbitrary files. Requires direct HTTPS, or the explicit
  **local** loopback proxy token and HTTPS forwarding assertion. Production cannot
  enable that proxy token or test/fixture/auth-bypass settings. `NQ_CONFIG_FILE` is
  rejected without opening it; the existing private template remains inert.

  certificates are trusted per cURL handle only. No global trust store changes.
  Processes use explicit small environments; PHP access output is discarded to
