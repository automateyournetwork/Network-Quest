## Findings and changes

The Workshop's selected inspection kit exposed its illustration to pointer users. Tab from the selected item wrapped to Close Inventory and skipped the native summary. The frame's forward and reverse Tab boundaries now include visible native summaries and respect disabled, hidden, inert and programmatically focused controls. Each frame window retains its own opener when another window opens on top. Manual frame buttons supply their actual opener for keyboard and pointer input. [Adventure frame](../../../src/ui/adventure-frame.ts)

Photon's opening and second lines were visible, but the dialogue exposed an empty accessible description and only announced “Dialogue ready.” The dialogue now exposes its current line as its description and updates the polite line announcement when the text changes. Scene recovery similarly exposes the visual failure message as the description of the window it opens. Letter and group-navigation shortcuts defer to text editing, IME composition, browser modifiers and held keys. [Dialogue](../../../src/ui/dialogue.ts) · [Semantic shell](../../../src/ui/app-shell.ts)

The historical Arrival Lift save loaded correctly and focused its migration notice. After Resume adventure, focus missed the new room heading. The application now waits for the room heading to leave the modal's inert background before completing that focus request. [Application](../../../src/app/application.ts)
