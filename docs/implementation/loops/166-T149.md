# Loop 166 — T149 responsive room layout

T149 passes the scoped responsive-layout checks for US5, FR-019/020 and AC14. The final build gives the Clockworks 310 CSS pixels of stage height at 390×844 with 200% text, up from 106. The Bit Loom, Compendium and all ten other commands remain on screen. The Iron Threshold also keeps its complete toolbar, including Diagnostics and Validate repair. [Before](../../evidence/spec001/accessibility/responsive-layout/R10-390-32px-before.png) · [After](../../evidence/spec001/accessibility/responsive-layout/R10-390-32px.png) · [Iron Threshold at 1280×720](../../evidence/spec001/accessibility/responsive-layout/R12-1280-16px.png)

The frame now sizes each toolbar command to its contents and lets all commands share rows. The icon, label and visible shortcut stay together. On narrow screens the header places the room and save status together and gives Sound and reading the wider button. Each range control can use the width of its settings window, with its current value next to the label. The existing semantic controls still receive pointer and keyboard actions. ## Measurements

Normal Firefox 159.0, Playwright revision 1572, ran on macOS 26.6.2 arm64 against the local game over HTTPS with disposable NSS trust and isolated PHP/SQLite. Each row covers a visit to both rendered rooms. Each of their twelve visible toolbar commands measured at least 44×44 CSS pixels, stayed within the monitor and received the center-point hit test. Compendium occupied one line, with its C shortcut beside it wherever shortcut hints were displayed. The document had zero horizontal and vertical overflow.
