editable meshes, rendered its inspection camera with Cycles, then exported a
material-batched GLB in memory. The reopen harness rechecked the source hash.
Firefox 159.0 loaded all twenty files through a disposable trusted local TLS
endpoint with Three.js r187. Every material name and triangle count agreed.

matched source and browser alpha masks was 97.84% on the thin radio mast.

highlights between the two renderers. [Pixel measurements](../../evidence/spec001/prop-production/T113/comparison.json)

## Reproduction

Run Blender with factory startup, background mode, two threads and Python
exit code 1. Run the adjacent build.py with the selected numeric IDs after
a double dash. Reopen each saved blend in its own process with reopen.py.
Run browser.mjs from the project root with the pinned Node runtime and all
twenty PR-prefixed IDs for the full staging capture. Run compare.py with
the project Pillow and NumPy interpreter, then inspect_glb.py with Python.
After review, records.py writes this run's typed fragment and records.
Regeneration produces new native bytes and requires a new inspection.
