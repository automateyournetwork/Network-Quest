Returning to a visual room resumed its renderer. The four new guest scenarios recorded zero non-GET requests and zero page errors. This covers the background-tab behavior in US5 and FR-021. ## Reproduced defects

Before the change, native Replay successfully played Photon while the status still told the player the tab was hidden. The Workshop cleared its music caption during the background interval. The packet scenario passed on its first run. The initial R04 test stopped at a modal boundary while attempting to open Diagnostics. After correcting the test to close Scene, an isolated build with the earlier sprite renderer produced one displayed frame while paused. The same test on the corrected renderer observed no displayed frame until return.

A unit case also reproduced a deferred scene input reaching its action handler while the adapter was paused. The room adapter now cancels pending visual inputs when hidden and rejects captures made while paused. A new foreground input still reaches the handler. The shared visibility listener applies the document's initial hidden state when each room, audio or packet owner mounts and follows native visibility changes until disposal. The audio panel gives an interrupted transient caption a fresh reading interval on return. ## Verification

The cases ran on macOS 26.6.2 arm64 with Node 26.13.1, Playwright 1.65.1 and Chrome for Testing 159.0.8154.6, revision 1255. Each scenario used the production guest build and a disposable loopback preview and Chrome profile. The runner attached over CDP with focus emulation disabled. Each transition checked the browser's actual document visibility. The title and Photon case also inspected the detached native media elements while leaving playback and decoding to Chromium. The joined visibility project passed all five cases. The strengthened native media assertions passed a subsequent targeted run. The five unit suites covering audio, room input and both packet journeys passed all 91 checks. TypeScript, authored-content validation and the save-policy check passed.
