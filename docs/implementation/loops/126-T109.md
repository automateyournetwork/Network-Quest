## Verification

Fresh, bounded two-thread Blender 5.2.1 processes reopened the eight native
files. The 432 editable mesh components retain named anatomy, local joints,
materials and NLA tracks. Export-time joins reduce them to 43 rigid meshes
across the cast. Every binary has one embedded geometry/animation buffer
and zero texture dependencies. An independent Blender import and Firefox
159 GLTFLoader render matched all 101,558 triangles across the eight exports.

The binary sampler check verified changing values in all 19 clips, stable
roots and matching start/end poses. Each ability has a presentation contact
at frame 24 of 48. The checks compare five actual native render-graph poses
per clip with Firefox AnimationMixer, 95 paired samples. The largest bound
difference was 0.34 mm. Integer-frame world matrix components matched within
0.00000029. Fractional-frame interpolation accounts for the measured
differences between sampled GLB transforms and native curve evaluations.
Each individual character directory contains native, browser and independent
import measurements with current file hashes.

Source/export visual inspection used all eight sheets. The coordinator reviewed
the initial Echo Bat render and requested clearer wing-tip separation. Thin
blue edge welts now trace the dark wing tips. The idle chest lifts above its
ground pivot. Chameleon's revised facial geometry keeps both eyes readable.
The revised Eel lanyard keeps its ledger visible when the head dips. The
initial dependency-graph check captured stale viewport joint transforms.
Sampling the evaluated Cycles render graph resolved the discrepancy. The
previous measurement, Eel contact view and Bat trough measurement retain the
superseded source/export hashes in the [revision evidence](../../evidence/spec001/character-production/T109/revisions/initial-pose-sampling.json).

## Reproduction

From the repository root, create the scratch directory `.local/t109/render`.
Run the project Blender executable with `--factory-startup -b -t 2
--python-exit-code 1 --python assets-src/characters/t109/build.py -- CH18 CH19
CH20 CH21 CH22 CH23 CH24 CH25` to reconstruct the editable sources. For
each source, pass its file path after `-b -t 2` in a fresh Blender process,
then `--python-exit-code 1 --python assets-src/characters/t109/reopen.py`.
An independent background call to `import_check.py` imports the eight GLBs.
Use pinned Node 26.13.1 to run `assets-src/characters/t109/browser.mjs`.
It creates a disposable TLS origin and Firefox profile, renders the samples
and removes its trust files. The project's existing Pillow environment runs
`sheets.py`. Plain Python 3 runs `verify.py`.
