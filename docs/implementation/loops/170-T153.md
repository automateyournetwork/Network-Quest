# Loop 170 · T153 desktop browser compatibility

**Verified November 28, 2026.** Eight browser distributions completed all twelve rooms at 1280 × 720, 1440 × 900, 768 × 900 and 390 × 844. The 32 final journeys each recorded 262 actions, nine diagnostic measurements, the permanent repair, a separate endpoint test and Continue. The two desktop sizes used full keyboard play with exact top-level content dimensions. The narrow widths exercised responsive controls in desktop engines.
