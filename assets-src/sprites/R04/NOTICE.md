OpenAI Codex assisted with the original Blender staging, lighting, software and review. Blender 5.2.1 rendered the actual Apprentice, Ancient Tortoise and Echo Bat from the project's original native rigs. The twelve apparatus cells use the project's original GLB prop exports. The editable sources and export hashes for each input are recorded in native-frames.json and in the character and prop production manifests. The native stage adds a small original conduit for the suspended insulator. The visible room scenery uses three earlier, separately credited project-generated layers. No scenery pixels are part of these sprite atlases.

Rebuild from the repository root with Blender in background factory-startup mode and assets-src/sprites/R04/render.py, then run pack.py with Pillow. The saved stage contains the source geometry and rigs. Passing --render-only after Blender's -- separator samples that saved stage without rebuilding it. Run contacts.py in Blender for independent floor-receiver comparisons. Native camera coordinates, lighting, clips and timestamps are in render.py and native-frames.json. The runtime consumes the exact crops and frame offsets in content/spec001/presentation/R04.json. Browser verification uses browser.mjs with the pinned Node, Firefox and local PHP environment. Running verify.py after the render and browser checks compares the exported sprite pixels, floor contacts and composed browser canvas.
