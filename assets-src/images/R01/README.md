# R01 generated scenery candidates

Three actual OpenAI built-in image-generation outputs were produced on
2026-11-26. All are **exported candidates**; none counts toward acceptance yet.
`manifest-candidates.json` is the T064 handoff fragment. Root owns the shared
manifest. T066 owns actual scene integration and T067 owns the finished-room,
performance and owner review. No bulk room production follows this task.

The exports total 2,145,421 bytes (about 2.05 MiB). At RGBA8, three decoded bases
are 18,880,224 bytes; a full mip-chain approximation is 25,173,632 bytes. These
are image-only estimates, not measured GPU memory or a full room budget result.
All source/export hashes are identical per layer. No crop, pixel repaint, manual
mask, format conversion or resampling was used to create the exports.

Each `*.prompt.txt` is the exact prompt sent. `*.settings.json` records the actual
arguments with workspace paths normalized; `*.tool-return.json` preserves the
reported artifact identifier and tool hint with only the local Codex home prefix
normalized. The built-in tool returned an inline image and output hint. It did
not expose model revision, seed, backend version or generation settings beyond
the supplied arguments. There is no invented technical model name. The first
prompt requested 2048×1152; the actual output was 1672×941 and the later two
requests used that observed size. All original generated bytes remain preserved.

The background used the copied T063 draft staging reference. The alpha-layer calls
used our own background and the corrected T063 reference. Both drafts are retained
in `reference-inputs/`, with their camera/anchor snapshots and actual hashes.
All anchor arrays match exactly. The final native rebuild's source fingerprint is
preserved in camera-v3/registration-v3. Final v3 PNG bytes differ from v2; actual
pixel comparison found at most one RGB level difference and identical alpha.
Invocation snapshots remain unchanged. See `input-permissions.md`, `NOTICE.md`, the
CC BY text and the dated official-provider terms review for the limited rights
finding. No historical game artwork or real-person likeness was used.

`camera.json` and `registration.json` bind the final T063 camera to these layers.
All three full canvases map to one centered 16×9 camera plane. The slight source
aspect difference produces a 1.000531632 horizontal display scale; this is an
explicit UV display transform, not a pixel-file edit. The current camera's
`heightSpan=max(9,13/aspect)` rule controls crop/letterbox at other viewports.
At 1440×900, the 1600×900 plane clips 80 pixels on each side; at 768/390 widths,
the bounded scene has vertical letterboxing. All inspected semantic anchors and
the source landing remain visible. No independent layer parallax is permitted.

Order: background → midground → real-time focal scene → foreground. PNG alpha is
preserved as unassociated alpha with normal source-over blending. The midground
is about 93.97% fully transparent; foreground about 97.53%. A small number of
alpha=1/255 residual pixels remain outside the visible shapes (15 and 34 in the
sampled central rectangle). They were preserved honestly. Sampled ±8 CSS-pixel
anchor margins contain no alpha above 1 for midground, and only zero alpha for
foreground. This is a pivot-margin check, not a complete selectable-bound or
human-readability proof. No essential label or numeric diagnostic is baked in.

Open `review.html` locally to inspect the editable layer stack over the actual
corrected v2 Blender source render used by the generation calls and eight native
captures. Final v3 was directly inspected and pixel-compared after T063's rebuild;
the review page intentionally retains its observed v2 input rather than silently
relabeling old captures. It uses separate source images; there is no
flattened replacement for the promised layers. Its optional query parameters are
`?layer=midground&matte=light` or `?layer=foreground&matte=dark`; `capture=1` hides
the evidence caption. The page is a production review, not an integrated game.

Actual validation on 2026-11-26:

  dimensions, alpha and unchanged export hashes saved in the inspection JSON.

  errors. Eight screenshots cover 1280×720, 1440×900, 768×900, 390×844 and both
  transparent layers on light/dark mattes. Agent inspected all eight.
- Independent Three.js projection and the browser's observed plane rectangles
  agree with T063's Blender anchor UVs within 0.000219 CSS pixels. This is numeric
  coordinate agreement, not claimed accuracy of painted geometric landmarks.
- `node tools/validate-assets.ts --manifest assets-src/images/R01/manifest-candidates.json`
  passes inventory checks with **zero accepted quota counts**.
