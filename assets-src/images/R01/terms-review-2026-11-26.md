# R01 generated-image terms review

Observed 2026-11-26 through the official public pages. This is a short review
snapshot, not a replacement for the linked terms. It supplements
`docs/evidence/spec001/licensing.md` and applies only to this own-image production.

- [Terms of Use](https://openai.com/policies/terms-of-use/), published/effective
  2026-01-01. Content ownership assigns OpenAI's interest, if any, in own output
  to the user to the extent permitted by law. Inputs require permission; outputs
  require evaluation, may be similar to other outputs, and must not be falsely
  represented as human-generated. No copyright exclusivity is established.
- [Services Agreement](https://openai.com/policies/services-agreement/), updated
  2025-12-01, effective 2026-01-01. Sections 4.1–4.4 contain the comparable own-output
  allocation and input/use responsibilities for business/developer services.
  No custom contract, subscription type, warranty or indemnity is inferred.
- [Service Terms](https://openai.com/policies/service-terms/), updated 2026-11-13.
  These take precedence on conflicts. Image inputs need necessary likeness rights;
  sharing others' media on a service does not grant outside reuse rights.

The reviewed common public output provisions support modification, redistribution
and commercial reuse of these own-image outputs within their conditions; no
noncommercial-only image-output restriction was found. The project offers only
its controlled rights under CC BY 4.0 (`LICENSE-ASSETS`). This does not establish
copyright where none exists, clear unknown third-party claims, or relicense the
provider's services. Account-specific terms are not exposed by the tool.

Production uses the built-in `image_gen__imagegen` tool. Precise model revision,
seed and backend settings are recorded only if returned. Reference inputs must be
original Network Quest Blender work or the project's own generated output, copied
and hashed in this source directory. No historical game media, external character,
logo, living artist imitation or real person's likeness is requested. The final
per-layer record binds actual inputs and outputs to this review; human owner art
acceptance and browser integration remain separate.
