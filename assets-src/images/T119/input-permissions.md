# Reference permissions

John Capobianco directed this Network Quest production. Four inputs combine the project's original fictional characters and props in a Blender render, the T106 camera and a project-authored guide to the walk surface and exits. Each room's reference/inputs.json identifies the source GLBs and their verified hashes, the native Blender version and the mounted transform report. All of these project-controlled inputs are released under CC BY 4.0. No imported commercial characters, third-party plates or photographs enter the production.

Each overlay and paving source used that room's generated background as a reference. The backdrop repair used the room's own first output. Each generation settings file preserves the actual reference order and source hashes. The standalone preview includes an additional original Blender shadow study for the posed models. Movable shadows stay separate from the public plates.
