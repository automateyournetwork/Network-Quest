# Reference inputs

John Capobianco directed this production for Network Quest. Each camera guide was assembled from the project's own character and prop GLBs on the project's frozen orthographic floor. Each room's reference/inputs.json identifies the individual file hashes and available cast. The floor, placement dots and cast are registration aids. Each overlay used the room's own previously generated background as a second creative input. The Workshop paving texture used its own background alone. Individual event settings preserve the actual order of reference paths and hashes. The source material contains fictional studio characters and project-authored environment geometry.

The final isolated cast renders also include the shared props that arrived after guide creation. They are inspection artifacts. Each final render carries its own input roster.
