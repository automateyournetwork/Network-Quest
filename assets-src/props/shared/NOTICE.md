OpenAI Codex assisted with procedural construction and visual inspection. The batch uses original meshes built from named editable components, the project workshop primitives, an original mosaic alphabet and the Underworld enamel palette. Blender supplied Cycles and the glTF exporter. Firefox used Three.js to render the GLBs. The project includes no external mesh, bitmap, texture or typeface in these thirty models. Pillow supplied review-sheet labels outside the models.

The instruments and fittings depict the apprentice's kit. The optical power meter has a blank receive-power reading in dBm. The channel analyzer has an illustrative survey trace. The message token bears the episode's two highlighted NQ payload bytes. Runtime evidence, endpoint responses and recovery results come from the room and notebook.
