# Workshop props

Credit “Network Quest — John Capobianco and contributors” when reusing the
PR011–020 original models, Blender scenes, exports and review images. These
creative materials use CC BY 4.0 to the extent the project controls the rights.
Retain the credit, license link and a description of changes. The full license

The owner supplied the Network Quest setting and Spec001 prop roster. OpenAI
Codex assisted with the original construction and inspection code. Blender
created the geometry and Cycles source renders. Firefox and Three.js rendered
the exported GLBs. The pieces, bent rods, diagrams, letter strokes, labels,
materials and flame profiles were constructed from original geometry.

The project-owned Arrival Lift source render, Titan character review sheet and
frozen room diagrams supplied proportions, colors and the intended camera.
These references retain their own records. The new machines incorporate no
third-party model, font glyphs, texture, image pixels, or imported furnishing.
The build reuses the project's original T109 primitive and studio code.
Modeled A/B markings use original hand-plotted strokes. The contact sheets
use the system font for capture captions only.

The ten existing R01 sources and exports retain the T063 notices and histories
linked from their original inventory entries.
