Network Quest, link the license and indicate changes. See the project
`NOTICE` and `LICENSE-ASSETS`. The modeling and verification code carries
Apache-2.0.

OpenAI Codex assisted with the original geometry, inscriptions, procedural
modeling code and verification. Blender 5.2.1 LTS produced the native
objects, standard material factors, Cycles studio images and GLB exports.
All fixtures and painted glyphs were constructed for Network Quest. These
models use no imported typeface, image, texture, character mesh or vendor
model. Three.js and Firefox rendered the export comparisons. Pillow composed
the evidence contact sheets using its bundled default annotation font.
The annotations are outside the models.

The project’s existing R01 set, character sheets, frozen room layouts, authored
optical encounters and art direction supplied the design context. The room
retains accessible text and current readings. The fixtures use deliberately
enlarged educational details and the numbers printed in the Vault belong to
its fictional exercise.
